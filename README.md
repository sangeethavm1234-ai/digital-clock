
# ⏰ Digital Clock

## 📌 About the Project
Digital Clock is a simple and responsive web application developed using HTML, CSS, and JavaScript. It displays the current time and date in a clean and user-friendly interface.

## ✨ Features
- Displays real-time clock.
- Shows current date.
- Simple and attractive design.
- User-friendly interface.
- Responsive layout.

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript

## 🚀 How to Run
1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. View the current time and date.
